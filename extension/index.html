📖 版本 Tag 后缀是什么意思

模型名格式为 名字:标签，常见后缀：

示例含义
:latest默认最新版本，等价于不带标签
:4b / :14b / :235b参数规模：4b ≈ 40 亿参数。数字越大越聪明，也越吃显存
:4b-q4_K_M量化等级：q4_K_M ≈ 4bit 中等量化（体积小、速度快、质量轻微下降，最常用）
:fp16 / :q8_0fp16 原始精度；q8_0 ≈ 8bit，接近原版但体积大
user/name社区用户上传的模型（未经官方审核）
云端标记带 cloud 能力的模型跑在 Ollama 云端，不占本机显存，需要账号登录
量化速记：q2/q3 压缩狠、质量下降明显；q4_K_M 均衡之选；q5/q6/q8 更接近原版、体积更大。同参数规模下优先选 q4_K_M。

💻 本机硬件与运行压力

压力评级按「模型运行估算占用」对比「显存 + 可用内存」得出：

  • 轻松 模型可整体放入显存，速度最快
  • 勉强 需部分放入内存或纯 CPU 运行，速度明显变慢
  • 基本不可运行 超出内存可承受范围

估算公式：文件大小 × 1.35 + 0.8GB（上下文开销），是粗略估计，仅供参考。

❓ 常见问题

  • 提示无法连接？先启动 Ollama 桌面版（或运行 ollama serve），再点页面顶部的「重试」。
  • 删除模型后磁盘没变化？Windows 可能延迟释放，稍等或重启资源管理器；确认在 Ollama 设置里模型存储盘的位置。
  • 模型回复很慢？运行压力显示「勉强」时说明在用内存/CPU，换更小参数或更低量化的版本（如 14b → 8b）。
  • embedding / 向量模型？不用于对话，用于文本向量化（搜索、RAG），体积小、随便跑。
