# Ollama Hub — Ollama 可视化控制台

一个**零依赖、单文件**的 Ollama 增强工具：在浏览器里搜索、安装（拉取）、卸载、管理 Ollama 模型，不用再去官网复制命令贴到命令行。

只需要 Node.js（≥18），无需 `npm install`，无任何第三方包。

## 启动

双击 `start.bat`，或：

```bash
node ollama_hub.mjs
```

会自动打开 `http://127.0.0.1:11435`（端口被占用时自动顺延，地址以控制台输出为准）。

```bash
node ollama_hub.mjs --port 8080   # 指定端口
node ollama_hub.mjs --no-open     # 不自动打开浏览器
```

前提：Ollama 正在运行（桌面版开着即可，或 `ollama serve`）。默认连接 `http://127.0.0.1:11434`，可用环境变量 `OLLAMA_HOST` 指定其它地址。

## 功能

**已安装**
- 查看本地模型：参数规模 / 量化等级 / 模型家族 / 能力标签 / 占用空间 / 更新时间
- 查看模型详情（参数定义、对话模板、Modelfile）
- 删除模型（带确认弹窗，一键释放磁盘空间）
- 复制 `ollama run` 命令

**模型市场**（数据来自 ollama.com，实时解析）
- 热门榜单（240+ 模型）与关键词搜索
- 每个模型的介绍、能力标签（tools / vision / thinking / embedding）、参数变体、下载量
- 展开查看全部版本 Tag：大小、上下文长度、输入类型、更新时间
- 一键拉取任意版本，实时进度条 + 速度显示（支持取消）
- 手动输入框：粘贴模型名甚至整条 `ollama pull xxx` 命令都能直接拉取（官网复制命令的兜底方案）

**运行中**
- 查看当前加载到内存/显存的模型及占用、剩余保活时间
- 手动立即卸载（平时交给 Ollama 自动卸载即可）

## 工作原理

```
浏览器 UI ──> ollama_hub.mjs (127.0.0.1:11435)
                ├── /ollama/*  → 反向代理本机 Ollama API (11434)，解决浏览器 CORS，
                │                 流式透传下载进度；仅监听 127.0.0.1，不对外暴露
                └── /hub/*     → 抓取并解析 ollama.com 的搜索/版本页面（2 分钟缓存）
```

- 本地服务只绑定 `127.0.0.1`，删除等操作只能由本机发起
- Ollama 未启动时页面顶部会显示横幅提示，启动后点「重试」即可
- ollama.com 页面结构若改版导致解析失败，模型市场会给出提示，仍可用「直接拉取」输入框手动拉取

## 文件

| 文件 | 说明 |
| --- | --- |
| `ollama_hub.mjs` | 服务端（代理 + 官网页面解析 + 静态文件），全部逻辑在这一个文件 |
| `public/index.html` | 前端界面（内联 CSS/JS，无外部资源，离线可用） |
| `start.bat` | Windows 双击启动脚本 |
